# Steam Recording Salvage

Recover and export Steam Game Recordings when Steam's in-client Export/Clip features fail.

## What it does
- Scans for Steam recording sessions (looks for `session.mpd`)
- Exports selected sessions to a playable `.mp4` using `ffmpeg`

## Roadmap
- v0.1: CLI scan + export
- v0.2: Minimal GUI
- v0.3: Bundle ffmpeg for one-click installs
- v1.0: Polished UI + screenshots + release packaging
